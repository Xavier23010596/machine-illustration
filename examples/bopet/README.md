# 案例：BOPET 双向拉伸薄膜产线（15 台设备）

一个完整的真实案例，可以当 few-shot 照着改。

| 文件 | 是什么 |
|---|---|
| `inventory.json` | 设备清单（15 台，含双 Subject、工段、点缀色、误认负向词） |
| `prompt-pack.md` | **脚本生成**的提示词包：每台两套（3D + 线稿），正向/负向分栏 |
| `prompt-pack.json` | 同一份内容的机读版，可直接喂批处理 |
| `manifest.json` | 出图登记表（seed / 参考图 / 采用文件），开跑前是空壳 |

重跑：

```bash
node ../../scripts/build-prompt-pack.mjs --in inventory.json --out .
```

## 五个可以直接抄的决定

### 1. 锚点选"最经典"的那台，不是"最重要"的那台

选了 **D03 单螺杆挤出机**：结构最标准化、最容易一眼判断画对没画对。
先跑它 4 张定调，其余 14 台以它为参考图（权重 0.4–0.6）。

> 如果锚点选了最难画的那台（比如拉幅机），你会在还没定调的时候就被结构问题困住。

### 2. 只剖 3 台

D04 过滤器（露滤芯）、D05 模头（露衣架流道）、D08 拉幅机（露链夹与膜幅）。

标准：**不剖开就看不出这是什么机器的**才剖。其余全封闭外壳——否则 15 张里有一半在赌模型能不能画对内部。

### 3. 每台都有一句"识别特征"

这是本案例最关键的一列。摘几条：

| 设备 | 识别特征句 | 不解的后果 |
|---|---|---|
| D03 挤出机 | `proportional character: long and low, roughly 6 times longer than it is tall` | 画成注塑机那种高胖机身 |
| D08 拉幅机 | `two endless chain rails diverging in a V shape, with clip units gripping both edges` | 画成隧道炉或传送带 |
| D09 测厚架 | `a top beam and a matching bottom beam forming a closed O-frame` | 画成安检门 |
| D06 冷鼓 | `mirror-finish chrome-plated roll` + `electrostatic pinning bar with a thin electrode wire` | 画成造纸机烘缸 |
| D10 检测站 | `no bottom beam`（与 D09 区分） | 和 D09 撞图 |

### 4. 误认负向词逐台点名

`extra_negative` 每一行都是"这台最容易被误认成的那台机器"。比反复改正文有效得多，
因为它直接压住了模型对该类设备的先验。

### 5. 图内零文字

15 张图里一个字母都没有。设备名、序号、箭头、图例全部后期叠加——这是这套图能在正式文档里用的前提。

## 从这份案例迁移到你的设备

1. 复制 `inventory.json`，把 15 台换成你的设备；
2. 保留 `stage` / `accent` / `hex` 的分配逻辑（一段一色、同色 ≤3 台）；
3. **每台重写 `subject_3d`**——这是唯一不能复制粘贴的部分；照 `references/03` 的四段模板写；
4. 给每台想一句"最容易被误认成什么"，填进 `extra_negative`；
5. 跑 `--check` 过一遍，再生成提示词包。
