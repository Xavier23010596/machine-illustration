# 多机总图排版

> 目标：把 N 张单机图排成一张 16:9 的产线示意图，读者能顺着箭头读完整个流程。
> 这里只给几何与规则；单机图的字号与配色见 `04-palette-and-labels.md`。

---

## 1. 画布与分区

基准画布 **3840 × 2160**（16:9，可无损降到 1920×1080 或 A3）。

| 区域 | y 范围 | 占比 | 内容 |
|---|---|---|---|
| 标题带 | 0–160 | 7% | 主标题 + 副标题（中英） |
| 段标题 | 180–260 | 4% | 段序号圆点 + 段名（中英各一行） |
| 设备图区 | 280–1560 | 59% | 单机图 + 图下名称 |
| 箭头带 | 与图区重叠 | — | 段间主流程箭头 |
| 辅助行 | 1600–1900 | 14% | 旁路设备（回收/公用工程）+ 虚线回路 |
| 图例 | 1980–2080 | 5% | 4–5 条箭头图例 + 口径注 |

> 与"单机图 1:1"配合：图区每列放一张方图，列内再放名称与编号。

---

## 2. 列宽公式（任意台数都能算）

```
列宽 = (画布宽 − 2×边距 − (列数−1)×列间距) / 列数
```

例：画布 3840、边距 120、列数 7、间距 40

```
(3840 − 240 − 240) / 7 = 480 px
```

**定列数的规则**：列数 = 主流程工段数（本例 7 段），**不是**设备台数。
一段里有 2–3 台时，在同一个列内**上下叠**或**缩到 ~230 px 并排**，不要为了塞机器去加列（列一多，箭头就没地方走）。

单机图统一缩到列宽（480×480）。缩完仍要锐利 → 出图不低于 1024×1024。

## 3. 箭头体系：最多 5 类

| 类型 | 线型 | 颜色 | 用途 |
|---|---|---|---|
| 物料流（主线） | 实线 8 px，圆头 | 深蓝 `#1E3A8A` | 贯穿全图，从第一段到最后一段 |
| 工艺流（分支） | 实线 6 px | 该段点缀色 | 段内短程（如熔体：挤出→过滤→模头→冷鼓） |
| 热媒/冷媒 | 实线 4 px | 青 `#0FA3A3` | 辅助区 → 用热点 |
| 控制信号 | 虚线 4 px（dash 12/8） | 灰 `#6B7280` | 检测 → 执行机构闭环 |
| 回流（边料等） | 虚线 4 px | 绿 `#2FA84F` | 末段 → 首段的回路 |

三条规则：

1. **超过 5 类就失去可读性**。这是硬上限，不是建议。要表达第 6 种关系，用文字注。
2. **主线只有一条**，且必须是全图最粗、最深的线。其余都退一档。
3. **箭头不穿机器**。绕不过去就说明排版该错位了（见 §4）。

---

## 4. 排布顺序与错位

- **顺序**：严格按流程 `D01 → D02 → … → D13`，读者默认从左到右读，不要为了"好看"打乱。
- **错位**：一段里有 2–3 台时，**上下错位摆放**（不是严格水平对齐）。理由有二：
  1. 给箭头让出穿行通道；
  2. 暗示"这些是同一段里的并联/串联设备"，而不是"一个更长的流程"。
- **辅助设备**（边料回收、公用工程）放在图区下方的辅助行，用虚线连回它服务的工段。
  它们不属于主流程，混进主线会让读者以为要经过它们。

---

## 5. 图例与口径注

图例只放**箭头类型**（4–5 条），不要放配色图例——配色靠段标题的圆点已经说明。

右下角固定两行小字：

```
Schematic — not to scale
示意图，非等比；设备外形为示意，不作为选型依据
```

这行字是保护性的：它会挡住"你这张图尺寸不对"的质疑，也提醒读者去看正文参数。

---

## 6. 合成流程（不依赖特定工具）

| 步骤 | 做法 |
|---|---|
| 1 | 建 3840×2160 画布，铺白色底（不是透明） |
| 2 | 按 §2 算列宽，拉参考线（每列一条中线） |
| 3 | 逐台贴入 480×480 方图，**先只放图不放字**，看整体节奏 |
| 4 | 统一加名称两行（中/英），基线对齐 |
| 5 | 画箭头：先主线，再分支，最后虚线回路 |
| 6 | 加段标题与序号圆点 |
| 7 | 加图例与口径注 |
| 8 | 导出 2× PNG（7680 宽）用于印刷，1× 用于网页 |

**第 3 步是关键**：先只放图，能立刻看出"哪一列太挤、哪一列太空、箭头有没有通道"。带上文字再调，会被文字干扰判断。

---

## 7. 总图自检

- [ ] 列数 = 工段数，不是设备数
- [ ] 所有单机图同一列宽、同一视觉重量
- [ ] 主线箭头最粗最深，且只有一条
- [ ] 箭头类型 ≤5，且不穿机器
- [ ] 段标题与配色一一对应
- [ ] 辅助设备在辅助行，未混入主线
- [ ] 右下角有"非等比"口径注
- [ ] 缩到 25% 看：还能读出流程顺序吗？（读不出说明箭头或列宽有问题）
