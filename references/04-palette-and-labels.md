# 配色与标注

---

## 1. 配色的唯一目的：让读者"一眼分段"

这套图里颜色**不是装饰，是索引**。机身永远白，彩色只出现在小构件上，读者靠颜色把 15 台机器归到 7 个工段。

### 三条硬规则

| 规则 | 值 | 为什么 |
|---|---|---|
| 点缀面积 | **< 10% 可见表面** | 超过就变成"彩色机器"，白机语言崩了 |
| 同色上限 | 一个色最多 **3 台** | 第 4 台开始，读者记不住"这个紫是拉伸段" |
| 同段同色 | 同工段必须严格同色 | 否则读者以为多了一个工段 |

### 色板怎么定

1. **先分段，再配色**。按流程分出 6–8 段（含辅助段）。
2. **相邻段色相要拉开**：蓝 → 青 → 绿 → 琥珀 → 紫 → 橙红 → 玫红，相邻段不撞色。
3. **全部中高饱和、低明度**。太亮会在白底上"发光"，太灰又分不出段。
4. **辅助段用中性灰**（`#6B7280`）。它不该抢主线。

参考色板（BOPET 实际使用，可直接改用）：

| 段 | 色名 | 色值 | 放在哪 |
|---|---|---|---|
| 1 原料与干燥 | deep blue | `#2E6BE6` | 机架、手轮、指示灯 |
| 2 熔融挤出 | teal | `#0FA3A3` | 机筒护罩、管路保温层 |
| 3 熔体过滤 | green | `#2FA84F` | 压环、压力表圈 |
| 4 铸片冷却 | amber | `#E08A00` | 模头护罩、端盖 |
| 5 双向拉伸 | violet | `#7A5AF8` | 辊架、门把手 |
| 6 在线检测 | orange-red | `#E4572E` | 扫描架、相机外壳棱线 |
| 7 牵引收卷分切 | rose-red | `#D6438A` | 收卷臂、护板 |
| 辅 公用工程/回收 | grey | `#6B7280` | 整体机架、控制箱 |

### 一台机器超过 3 台的段怎么办

换**同色系的深浅两档**（`#2E6BE6` / `#5B8FF0`），仍然算同一段。不要引入新色相。

## 2. 图内不写字，那标注怎么来

**分两件事：出图（无字）→ 标注（另一道工序）。**

### 2.1 标注元素清单

| 元素 | 内容 | 位置 |
|---|---|---|
| 图号 | `D03` | 图左上角或正上方，小号 |
| 中文名 | 单螺杆挤出机 | 图下方第一行 |
| 英文名 | Single-Screw Extruder | 图下方第二行，灰 |
| 序号圆点 | 1–15 | 总图用，单机图不用 |
| 图例 | 箭头类型 | 总图底部 |
| 口径注 | "示意图，非等比" | 总图右下角小字 |

### 2.2 字号阶梯（按最终印刷/投影尺寸定，不按屏幕）

| 层级 | 字号 | 字体 |
|---|---|---|
| 总图主标题 | 72 px（3840 宽画布） | 思源黑 Medium / Inter Medium |
| 段标题 | 40 px | 同上 |
| 设备中文名 | 32 px | 思源黑 Medium |
| 设备英文名 | 24 px（`#6B7280`） | Inter Medium |
| 图例 / 注 | 24 px | Inter Regular |
| 序号圆点 | 直径 44 px，数字 28 px 反白 | — |

单机图若单独成页，按比例放大：中文名约为图宽的 4%，英文名 3%。

### 2.3 三条可读性经验

1. **中英双行永远比单行好**。中文给读者，英文给检索与国际读者。
2. **英文名用 `.not-italic`、颜色降一档**，读者自然先读中文——层次靠颜色不靠字号。
3. **标注不许压图**。机器下方留 ≥8% 图高做标注带，宁可将机器缩 5%，也不要让文字压在机身上。

---

## 3. 单位与口径

- 图上**不标尺寸线**（除非是尺寸示意图）。尺寸靠正文与表格说，标注里只放"非等比"这类口径。
- 若确实要标尺寸：只标**一个**关键值（幅宽、辊径、腔体长度），其余不给，避免读者以为这是施工图。
- 示意图与实测图必须区分：示意图右下角小字 `Schematic — not to scale`。

---

## 4. 配色自检

- [ ] 每个工段一个色，相邻段色相拉开
- [ ] 单台机器彩色面积目测 <10%
- [ ] 同色不超过 3 台
- [ ] 机身统一白（不是"米白/浅灰混用"）
- [ ] 辅助设备用中性灰，不抢主线
- [ ] 深色底/彩色底一律不用（会与白皮书语境冲突）
